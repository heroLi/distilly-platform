# Distilly 合成文字测试预览

这是从现有人物工作室体验提取的静态演示包，沿用米白底、绿色按钮及卡片布局；没有修改正式页面、业务 API 或默认聊天协议。源码位于 `preview/synthetic-text/dist/`。

## 本机运行

无需安装依赖或填写任何令牌。在此目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

然后打开 `http://127.0.0.1:8080`。请通过 HTTP 打开，避免 `file://` 的脚本安全策略差异。停止时在终端按 Ctrl+C。静态托管时以 `dist/` 为网站根目录；所有资源使用相对路径。不要将业务仓库、数据库或 `.env` 一并上传。

## 五分钟操作路径

1. 点击“打个招呼”，查看 AI 身份及脚本提示。
2. 点击“发送散步示例”：虚构访客在周六上午到月湾公园散步。
3. 手机点“记忆”，PC 查看右侧记忆卡。先“查看来源”，再“确认留下”。不确认时询问安排会显示未知。
4. 切到“再次交流”，点“询问散步安排”。脚本仅读取当前访客已确认且来源版本有效的合成记录。
5. 将记忆纠正为周日，再次询问；来源原文仍保留周六，记录会注明用户纠错与新版本。
6. 点击“遗忘这条”，再次询问显示没有可用记忆。原交流历史保留，记忆卡正文清除。
7. 可在来源窗口模拟来源纠错，验证旧确认失效；也可切换合成访客 B，查看独立空态。
8. 发送后可立即停止，再显式重试；不会重复添加原消息。刷新、重置或“清空并离开”会清除本页记录。

## 实现与模拟边界

- 实际在浏览器运行：发送/停止/显式重试、重复点击保护、候选确认、固定示例纠错、来源版本失效、撤回/遗忘、两个合成访客的内存分区、响应式页面和安全文本显示。
- 回答完全为预设脚本；候选仅由精确的合成示例触发，不从自由正文提取，不声称语义理解、事实支持判定或真实人格质量通过。
- 不运行服务器鉴权、SQL、Python Worker、Hindsight、真实模型或音频服务。访客切换不是登录功能。没有文件导入或私人资料上传入口。
- 不使用 cookie、localStorage、IndexedDB 或远端接口。内容仅在本页 JavaScript 内存中存在，不跨设备同步。页面 CSP 禁止连接请求。托管服务仍可能按其自身规则记录普通页面访问元数据，页面无法代替平台隐私政策。
- 记忆遗忘与原聊天保留是为展示既有边界，不代表正式产品的新删除政策。已看到的内容无法追回。
- 原有中文 12/21、窄探针 0/4、自由回答事实支持缺口及旧 247 未恢复均未因这个演示改变。

## 检查与打包

仓库根目录：

```sh
node tests/synthetic_preview_test.cjs
DISTILLY_TEST_CHROMIUM=/usr/bin/chromium python3 tests/synthetic_preview_browser.py
python3 scripts/package_synthetic_preview.py --output /tmp/distilly-synthetic-preview.zip
```

打包器仅纳入四个明确列出的网页文件、本说明和逐文件 SHA-256 清单；不递归收集仓库、不含工作树、测试日志、截图、凭据或数据库。此包可交由主会话进行 Sites 私密托管；当前没有 Site ID、访问链接或部署记录，不应冒称已上线。
