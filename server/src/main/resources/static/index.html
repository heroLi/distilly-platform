人物形象

上传 PNG、JPEG 或 WebP（最多 1 MiB），或通过已配置的图像模型生成。

图像生成需由管理员接入图像服务。当前形象随文字情绪与朗读做轻量动画，不是三维数字人或模型生成口型。

浏览器声音

使用当前浏览器提供的声音。语气与语速跟随情感状态，支持打断。

语音输入由浏览器识别服务处理，部分浏览器会发送音频至其服务；只在你点击并授权麦克风后启动，识别内容填入输入框，由你发送。

模型语音与音频转写

独立语音网关提供更稳定的合成和音频识别；需由管理员接入语音服务。
