成员与角色

负责人 OWNER

管理项目成员、上传材料、生成候选、审核发布、切换版本、删除与恢复主题，管理全部历史任务及查看审计。

编辑者 EDITOR

上传材料、创建主题、生成及查看候选与来源；查看任务并重试失败任务，可删除或恢复自己提交的历史任务。审核发布和成员管理由负责人完成。

阅读者 VIEWER

查看已发布经验、提问与下载工作Skill；只查看自己的问答任务，并可删除或恢复自己的历史问答。原材料与待审核候选不可访问。

项目成员管理

角色按项目分配；账号需先由管理员配置。不能修改自己的角色。
