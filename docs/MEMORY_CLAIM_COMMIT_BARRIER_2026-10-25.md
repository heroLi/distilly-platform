## 真实复现

已有记忆纠错会更新正文并取消同用户、同人物的活动聊天，完成时也检查确认状态和来源归属。但记忆 ID 在正文纠错后不变，存在取消扫描后的提交窗口：

1. 纠错事务已更新记忆、执行取消扫描，尚未提交。
2. 另一会话创建了新聊天，因此不在刚结束的取消扫描中。
3. 领取事务仍能读到旧的已提交正文，持久化相同的记忆 ID。
4. 纠错提交后，完成回执通过现有 ID/确认/归属检查，写入由旧快照生成的回答。

专用 H2 集成红测以真实服务和事务固定该交错，未修改生产数据库或拼造 API 输出：纠错外层事务在取消完成后暂缓提交，另一连接创建/领取新任务，释放纠错提交后再提交合法合成回复。结果为 **旧快照匹配当前正文 false、旧回复匹配当前正文 false、实际新增 assistant 1 条**；不是仅检查锁顺序，也不是一次真实模型质量测量。原始红测及 `red.json` 保留在忽略目录 `data/resume-20261025/memory-claim/`。
