# 当前资料记录卡问答（2026-10-21）

本文件记录首个记录卡阶段的契约与测试。后续已兼容新增可选 `filters`、`filter_contract` 和 `applied_filters`，当前日期/精确编号规则及新回归见 [显式筛选契约](RECORD_LITERAL_FILTERS_2026-10-21.md)。下列历史结果保留，不代替后续回归。

这是 Git 续做基线上的新增能力，不代表找回旧 247 项候选或旧 A 实现。

`POST /api/personas/{id}/record-questions` 只接受 `{"question":"..."}`，非空且不超过 4000 字符。所有角色都需要同空间权限及当前已审核发布的人格。响应契约 `RECORD_CARDS_V1` 包含当前人格版本、固定提示、最多 12 张当前记录卡（正文总计不超过 16000 字符）及 `model_calls: 0`。响应使用 `Cache-Control: no-store`。

这是确定性词法检索，不生成自由回答，不调用 Worker 或模型，不写任务、会话、消息、记忆或问题正文审计。卡片是已审核工作资料原文，不证明人物亲历或客观真相。空命中只表示当前检索没有找到匹配记录，不表示事件从未发生。

读取依次锁定当前成员、人格和按 ID 排序的选中资料；在锁内重新检查人格并从当前 `published_id`、`APPROVED`、同空间、未归档且仍选中的资料取卡。旧审核快照不能作为当前卡片返回。纠错使用现有 OWNER 专属 `PUT /api/profiles/{id}/claims/{claim_id}`，需要当前 `version_id`；成功生成新审核版本，旧版本请求返回 409。原材料与原证据保持不变；人工修订的文字不会被宣称为已经过独立证实。再次读取会显示新版本。

边界：既有自由聊天仍是独立路径；真实文字模型出口继续由费用核验门禁关闭，尚无累计费用账本或真实模型验收。已有页面收到的文本无法由服务器追溯收回；新面板会在重核、切换上下文、退出及当前访问错误时清除或更新卡片。权限和版本保证以服务器本次读取事务为准。词法检索尚未解决历史 摄影/拍照、散心/漫步、coffee/咖啡、安静/宁静 四项语义失败；原独立样本与报告未恢复，不能计算新通过率。

运行回归：`python3 scripts/verify.py --e2e`。隔离合成里程碑：`python3 tests/record_cards_e2e.py --output server/target/record-cards-e2e`。测试使用合成 TXT、mock Worker、本机回环 HTTP 和独立文件 H2，不需要密钥，不创建生产资源。完整测试结果以本轮执行证据为准。
