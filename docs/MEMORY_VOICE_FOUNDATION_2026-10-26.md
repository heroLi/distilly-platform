# 人物长期记忆与声音克隆：首批底座

日期：2026-10-26。从原工作区、干净的 `resume/text-cost-gate-20261021` 分支 `cb0614b3d3f5b2e255fd4cfe0037611b0afb0c29` 继续，本地与远端起点一致，无其他编辑代理。用户批准两块开始开发；没有把这项批准解释为真人录音、真实模型、凭据、付费、部署或手机/PC 新视觉的授权。

## 现状与首批范围

现有长期记忆并非空白：聊天输出可提议当前用户消息的候选，候选需要用户确认；记忆按人物和用户持久保存，可以跨会话检索、纠错、不采用和遗忘，完成时复核来源与权限，相关修改会取消旧上下文任务。当前 mock 候选是关键词模拟，检索是有限词法相关性，不证明真实提取准确率或普遍语义理解。

本批补齐两个实际缺口：记忆卡可查看原始消息；当前页面提交纠错或确认时带当前状态指纹，拒绝旧页面覆盖。走查又复现晚到后台读取覆盖正在编辑的卡片，已补齐草稿保护。没有另建记忆系统、安装 Hindsight 或修改召回规则。

已有浏览器朗读和 TTS/ASR 网关不等于声音克隆。本批在 `modules/media` 增加独立克隆档案与授权记录，Python Worker 增加供应商接口、mock 实现和永久关闭的真实实现占位。演示贯通创建、排队/处理/完成状态、试听、撤销和删除。**试听为 400 ms、440 Hz 合成提示音，没有语音，不代表任何人物音色，更不代表真实克隆质量。**

## 记忆契约

- `GET /api/personas/{id}/memories` 增加 `revision`。这是 ID、当前状态和正文的 SHA-256 状态指纹，不是单调 revision 计数、修订历史或外部同步版本。
- `PUT /api/personas/{id}/memories/{m}` 可带 `expected_revision`。在既有锁内比较，不一致返回 409 `memory_revision_conflict`，不写入、不执行后续取消；省略字段的旧 API 客户端仍兼容，不能声称它们也获得冲突保护。当前页面确认、纠错和不采用均携带指纹；遗忘仍按现有明确删除操作处理。
- `GET /api/personas/{id}/memories/{m}/source` 通过记忆→用户消息→原会话做双重用户/人物约束，只返回当前本人来源的消息 ID、会话 ID、标题、时间和正文。负责人也不能看他人来源；遗忘后或伪造外部来源返回不可用。纠错不改写原消息。
- 卡片输入后标记为草稿；后台读取开始前及返回后均检查，保留草稿。成功保存时仅在正文未继续编辑的情况下清理本卡草稿标记；删除成功立即移除本卡。用户可主动“刷新记忆（重载草稿）”，只放弃点击前的草稿，发出请求后新输入的草稿仍保护。冲突时不自动重发或强制覆盖。
- 来源弹窗使用 textContent；关闭、切换人物/空间、退出或离开页面使晚到响应失效。没有将他人私人记忆公开到人物资产。

## 克隆底座契约

追加迁移 `V011__synthetic_voice_profiles.sql`，保留 V001～V010 不变。`voice_profile` 保存人物/创建者、合成名称、幂等请求 ID、授权 ID、`SYNTHETIC_ONLY` 依据、`MOCK_PREVIEW` 用途、授权状态、授予及首次关闭时间。`voice_profile_job` 关联现有租约任务，不另建调度服务。授权仅证明用户在界面批准本次模拟，不是对任何真人音色的合法使用证明，也未实现真实授权证据上传、核验或到期策略。

| 入口 | 首批行为 |
|---|---|
| `GET/POST /api/personas/{id}/voice-profiles` | 仅当前创建者的档案列表；编辑者或负责人以显式 synthetic_consent 创建，必须 UUID request_id |
| `GET /api/personas/{id}/voice-profiles/{v}` | 私有状态与任务结果；即使是另一负责人也不能读取 |
| `POST .../{v}/preview` | 已完成 mock 创建且授权有效才能提交固定测试音；仅接收 request_id |
| `POST .../{v}/revoke` | 幂等撤销，取消关联任务并清空缓存音频、引用、payload 和租约 |
| `DELETE .../{v}` | 另外清空名称，从普通列表移除，保留最小授权关闭墓碑；不恢复授权 |

创建接口只允许 name、synthetic_consent、request_id，拒绝录音、外部 URL、文件路径和供应商配置。相同人物/用户/操作键重复或并发创建只保留一个档案和任务；同键改名冲突，不跨用户合并。试听也复用操作键。前端不自动重发未知操作；当前页显式重试沿用原键，刷新后先显示已有档案，不自动新建。

VOICE_CLONE/VOICE_PREVIEW 复用原 Worker 租约、重启接管和重复完成机制，发出租约及完成前检查角色、本人范围与授权。与撤销采用相同人物锁，撤销后旧完成回调不能复活资源；降为 VIEWER 的排队声音任务不再执行。通用任务列表也按私人声音任务隔离，关闭档案的历史任务仅保留安全状态，不暴露缓存结果。

Python `VoiceCloneProvider` 定义 create/preview；`MockVoiceCloneProvider` 返回稳定 mock 引用及标准库生成的 WAV。`DisabledVoiceCloneProvider` 拒绝真实操作。执行入口必须 Worker 为 mock、provider 为 mock、synthetic=true，拒绝额外参数，校验发生在任何配置或外部 IO 之前。没有接入 VoiceStudio、真实声纹、录音上传、真实 TTS 音色绑定、声音发布或聊天声音切换。

撤销在服务端立即阻止后续读取/执行并清理缓存；当前页主动撤销立即停止播放器，其他页面通过轮询核对后停止。已交付到客户端或另存的音频无法追回；离线页面不承诺即时远程销毁。删除只证明本平台 mock 数据清理，不能代表不存在的外部供应商删除回执。
