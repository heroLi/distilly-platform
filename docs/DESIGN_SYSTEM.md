# 统一风格与交互规范

日期：2026-10-08。适用于人物工作室与虚拟经历台。

## 风格来源

沿用现有工作室的浅色背景、深绿色主操作、白色面板与柔和边框。公共源为 `server/src/main/resources/static/design-system.css`，两页面在业务样式后加载它，覆盖公共控件；`persona.css` 与 `style.css` 负责各自业务布局。新功能不得在页面中另设主题色、基础按钮、输入框、品牌或弹窗规范。

| Token | 用途 |
|---|---|
| --ink / --muted | 主正文 / 次要说明 |
| --accent / --accent-hover | 主操作 / 悬停 |
| --paper / --white / --soft | 页面 / 面板 / 选中背景 |
| --line / --danger | 边框 / 危险操作 |
| --radius-control / --radius-panel | 控件 9px / 面板 16px |
| --space-panel | 桌面 24px / 小屏 18px |

当前两套业务 CSS 仍含历史字面颜色和布局规则，公共基础控件已经统一；后续逐模块去除被覆盖的规则，不把此次改动描述为全量前端重构。

## 信息架构与名称

- 人物：具体可交流的对象；人格：可复用的性格与表达配置；版本：冻结的配置快照。
- 人物经历：授权事实或原创背景；知识专题：共享的知识；关系记忆：某用户与人物的私人交流事实。
- 人物工作室：人物选择、设定与绑定、交流与记忆、声音与形象、成员与设置。
- 虚拟经历台：人格资产、材料、知识专题、生成任务与审核。保留既有名称和路由。
- 产品控件使用中文名称；relationship、celebrity、colleague 等内部枚举只用于接口。供应商环境变量放接入文档，页面只说明是否可用及如何处理。

## 页面与交互

1. 管理页面使用顶部搜索与筛选、表格、行内操作和底部分页。新增、编辑、生成、审核进入弹窗或详情；参照既有材料与人格库页面。
2. 交流页面保留人物、消息时间线、输入框与记忆区域，避免将管理表格塞进聊天流。
3. 品牌、主按钮、危险按钮、输入框、徽标和选中导航复用共享样式。每个区域只设置一个最主要的下一步。
4. 模态交互使用原生 `<dialog>` + `showModal()`。标题有可访问名称，Esc 取消，Tab 由浏览器限制在弹窗内，关闭后恢复触发控件焦点。动态经历台弹窗统一通过 `ExperienceUI.modal`。
5. 提交中禁用提交控件，失败保留输入和行内提示；不要让 toast 成为长表单的唯一错误提示。全局状态用 `role=status`，需要立即处理的错误用 `role=alert`。
6. 删除、停止和切换发布版本说明影响。长期记忆删除与聊天消息删除分开表述；当前记忆关闭不等于数据删除。
7. “排队中 / 执行中 / 已完成”是任务状态，“待审核 / 已发布 / 已拒绝”是内容状态，不能以任务完成替代审核发布。
8. 语音与视频不可用时解释能力状态，保留文字交流。供应商配置、浏览器支持与麦克风权限是三个独立状态，不合并为一个“支持语音”。

## 屏幕与可访问性检查

桌面和 390px 宽页面均核对品牌、导航、主操作、对话框及表格；小屏表格在自身容器横向滚动，页面不得整体横向溢出。按钮、链接、输入框和 summary 有可见键盘焦点；禁用状态不靠文字颜色单独表达。尊重减少动画设置。

每次新增页面核对：空状态、加载、成功、失败、权限受限、媒体未配置。截图检查不等于无障碍合规证明；还需键盘、焦点顺序、屏幕阅读器及对比度实测。
