# 虚拟经历台页面约定

默认采用「上方搜索与筛选 → 下方表格列表 → 分页」布局，参照材料管理。此规则同样适用于后续模块，除非用户明确指定其他形式。

- 知识专题、人格、材料、任务、成员、工作空间和操作记录均有搜索入口。材料/知识任务沿用服务端分页，其他小规模集合按权限获取后前端搜索分页。
- 新增、编辑、生成与审核使用弹窗或详情，列表保持简洁。弹窗可通过关闭按钮或Escape退出，关闭后焦点返回入口。
- 人格列表提供「查看详情」和「生成」操作。详情分为人格内容、原始设定、材料来源、绑定虚拟人、生成任务；切换版本可核对内容、分析和来源。
- 人格详情显示当前有效绑定的虚拟人及源版本，历史已替换绑定保留在人物版本记录中。归档人物不列入当前绑定列表。
- 多材料生成使用可搜索分页列表，跨页勾选保留。候选修改、批准/拒绝和绑定操作放在详情中。
- 负责人可看工作空间成员，其他角色只展示自己的账号和角色；角色权限说明属于辅助折叠内容，不扩大访问范围。来源原文仍限负责人/编辑者。
- 人格文档使用安全的标题、段落、列表与引用块展示，不执行未信任的HTML；正文、设定、来源均通过textContent填入。

本次浏览器验收覆盖搜索/筛选/重置、人格内容与来源详情、弹窗关闭、新增入口及模块导航；服务端回归核对绑定查询。

## 2026-10-05：参考 JD 平台的知识交互

- 专题详情分开展示已审核知识与专题蒸馏任务，候选在任务详情审核；任务详情仅展示该任务对应版本，不提供发布版本切换。
- 专题详情直接追加蒸馏，材料支持搜索分页，跨页保留选择；提交后进入任务列表，不打开其他专题详情。
- 全局任务列表同时展示任务执行状态和经验审核状态。问答任务详情显示该任务回答、固定版本和引用。
- 专题任务采用服务端分页 `/api/profiles/{f}/jobs/page`，支持搜索和任务状态筛选，仅负责人/编辑者访问；按专题隔离，不受旧任务列表200条上限影响。
- 任务详情显示累积快照语义、基础版本及可计算的新增条数；审核按钮提交期间锁定，成功后刷新任务与专题。
- 原材料和结论仍以文本安全渲染，保持人格生成、绑定及角色边界。

验证：49项Java测试（含专题任务隔离、审核状态、阅读者拒绝和分页参数），知识HTTP端到端流程与持久化重启检查通过；浏览器实际核对候选预览、批准发布、专题内容及问答/下载入口刷新、追加蒸馏材料选择；Node回归覆盖任务回答与固定版本、候选隔离、阅读者隐藏和关闭弹窗后的迟到响应。样例使用虚构材料与模拟/HTTP测试模型，不代表真实模型质量验收。

固定端口后的知识与虚拟人HTTP端到端回归均通过，覆盖知识发布引用、人格生成绑定、私有交流/记忆、SSE、媒体测试网关与重启持久化。本地预览固定18080；测试使用固定18082–18085。

## 2026-10-05：删除已审核蒸馏知识

负责人可在专题蒸馏任务、全局任务操作和任务详情点击「删除对应知识」。确认弹窗说明累积快照的影响：对应版本与继承它的后续版本均撤下；受影响的当前发布指针清空；原材料保留，恢复历史任务不会恢复知识。未审核任务、跨专题任务和非负责人均不可执行。存在排队、执行或暂停中的专题任务时拒绝删除，须先完成或停止。

删除采用版本DELETED标记并保留审计记录，已删除版本不出现在知识详情，不可回退或审核发布。未受影响的较早已审核版本仍可设为当前发布。

删除知识验收：51项Java测试通过；新增HTTP端到端验证覆盖删除后问答/下载返回409、原材料保留、恢复历史任务仍显示DELETED；Node检查负责人删除入口与编辑者隐藏。当前18080旧预览使用内存库且有新增内容，因安全保全未完成而未重启，代码构建已更新，现有页面暂未加载删除功能。
