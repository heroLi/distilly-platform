# 长对话上下文范围说明

本轮在原工作区 `c3929c520a8f88dbed046f6f228729c9e480973f` 基线核查并修复一个可复现缺口：输入已省略部分历史，但聊天回应没有用户可见说明。没有新增记忆架构、摘要生成、语义模型或费用策略。

## 两种历史省略必须分开

领取聊天任务时，既有查询仅选当前会话中除本轮消息外最近 24 条消息作为历史候选，随后统一容量装配器在历史、确认记忆、背景摘录和工作资料之间选择可容纳项目。当前输入与固定人格完整保留，无法容纳时任务显式 CONTEXT_LIMIT 失败。

旧 `omitted_history` 只计算这 24 条候选中因容量未纳入的数量，不包含窗口之外的更早消息。本轮在同一领取事务内统计当前会话历史总数，保存 `history_outside_window`，并在容量估算前加入元数据。没有改变选取/排名算法、检索规则或上下文上限；新增元数据计入同一容量估算，边界处能装入的候选数量可能相应变化。

完成回应沿用既有任务结果持久化。本轮私有会话读取只向对应助手消息添加 `context_scope` 数值白名单：

| 字段 | 含义 |
| --- | --- |
| `history_window_limit` | 当前历史候选窗口上限 24 条消息，不是 24 轮 |
| `history_outside_window` | 本次窗口之外未纳入的历史消息数；旧结果缺失时不补成 0 |
| `omitted_history` | 历史候选因容量未纳入的数量 |
| `omitted_memories` | 本轮已召回确认记忆候选因容量未纳入的数量 |
| `omitted_experiences` | 本轮背景/授权摘录候选因容量未纳入的数量 |
| `omitted_knowledge` | 本轮已检索工作资料候选因容量未纳入的数量 |

未命中或检索阶段未选入的资料不在这四项容量计数内。数量不能证明全部资料已被检索，不能说明真实模型如何使用输入，也不是 token 或费用。省略不表示已删除或从未发生。

## 页面与兼容边界

现有聊天气泡增加折叠的范围说明。只要已知有省略，标题明确提示“本条回应省略了部分上下文”；详情区分窗口外历史与候选容量省略。生成时的计数不证明资料当前仍获授权，不会随之后的记忆纠正或知识撤回改写。

旧结果只有原四项计数时，显示窗口外更早历史未计数；完全缺失或数据不合法时显示“本条回应的上下文范围未记录”，不能伪造零省略。正常用户消息和未完成的临时回应不附加成功回应计数。无新接口、迁移或来源正文查询，旧客户端可忽略新增字段。

会话授权检查先于读取；任务结果查询同时约束会话、创建用户、CHAT 类型与成功终态。输出白名单不包括任何来源 ID、正文、提示词、租约或模型配置。页面复用既有会话读取和生命周期隔离，不新增异步缓存；切会话晚响应、归档失权和退出不会留下旧计数。
