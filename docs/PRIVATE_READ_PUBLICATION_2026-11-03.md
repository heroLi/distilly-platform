# 普通私人读取的最终 SQL 复核

事实基线：`90f9efd380142c089fcfe910c67580eea60265f0`，原工作区与 `resume/text-cost-gate-20261021`。
本批在用户既定权限、来源及版本复核原则下，只处理会话详情、私人记忆管理列表、原始消息来源三个普通读取入口。
原文参考 `MemoryReferenceService` 的事务授权快照合同及实现保持，不改模型、检索、遗忘或计费语义。

## 新检查点与边界

普通读取先按原流程取数，返回前再执行一次同时带当前成员、人物未归档及私人归属条件的 SQL 复读。
**检查点是该最终 SQL 的获准视图，不是 JSON 写出、HTTP 提交或客户端收到字节的时刻。**
成员撤权／人物归档或已选来源变更发生在检查点前时，不返回旧私人正文；检查点之后发生变更，已获准的快照仍可完成，后续新请求使用新状态。
不承诺零窗口或收回已发送、已排队及客户端保存的数据，也不把整个请求称为串行化事务。

没有增加 `FOR UPDATE`、新事务、`REQUIRES_NEW` 或隔离级别设置，因此不把现有写事务的锁延长到读取、序列化或网络 I/O，也不反向获取新的成员／人物写锁。
嵌套创建会话时使用现有事务连接，可读取本事务尚未提交的新会话；真实 HTTP 持锁对照验证普通读取不等待已有写事务的成员／人物／会话行锁。
这是 H2 下的确定性验证，不是生产 PostgreSQL 压测或任何调度下绝无死锁的保证。

本地 H2 2.3.232 的语句路径已核对官方固定版本源码：
[SessionLocal](https://github.com/h2database/h2database/blob/version-2.3.232/h2/src/main/org/h2/engine/SessionLocal.java) 把语句依赖传给
[Transaction](https://github.com/h2database/h2database/blob/version-2.3.232/h2/src/main/org/h2/mvstore/tx/Transaction.java) 建立语句视图。
这支持把本批复核放在同一 SQL 中，而非把几次独立查询误称为原子检查；没有据此宣称跨数据库的整个请求快照保证。

## 实现范围

- **记忆列表**：最终 SQL 同时检查当前工作空间成员和人物状态；每条已选记录的内容、确认状态、来源链接与所属仍须相同。已删除／纠错／拒绝／换来源的记录返回 `409 private_read_changed`。允许新记录追加而保留较早的合法列表快照，不承诺这一列表包含检查点时的最新全集。管理列表仍包含本人待确认／拒绝记录，不是来源真实性或语义支持证明。
- **原始来源**：最终 SQL 联查当前成员、人物、本人记忆、本人来源会话和 user 消息；复核已选消息及来源会话固定版本。来源消失返回 404，当前失权按原规则拒绝，版本／内容不一致返回 409。纠错的是记忆记录正文，未改写的原始用户消息仍可合法读取；公开字段保持原来的五项，不暴露内部版本标记。
- **会话详情**：最终 SQL 核对当前成员、人物、本人会话和固定版本；已选在途任务被取消或失效时返回 409，避免纠错后复活旧片段。正常领取、继续生成或合法完成可保留较早的授权进度快照；人物发布指针变化不改变已有会话的固定版本，也不抹掉历史回答。
- 现有尝试次数在手动重试时会重置，不能独自标识旧片段所属的领取。非空片段还须匹配同一次内部领取；无片段的正常排队／领取允许推进。内部校验字段只在服务器使用，公开任务和来源响应采用字段白名单，内部领取标识不会进入 JSON。
- 前端只为新的 409 显示可操作的“资料或交流状态在读取时变化，请刷新后重试”，并递增已有脚本资源版本。没有新视觉、配置页或自动重发。

身份仍由原鉴权过滤器识别；本批最终复核范围是上述工作空间／人物／私人记录及版本，不新增全局退出或整站所有读取端点的保证。
原文参考的独立锁序、SQL 字面记录、`NOT_ASSESSED` 状态和已承诺快照规则均未更改。
