## 契约与失败恢复

- GET `/api/personas/{p}/memory-sync`：当前用户最新 50 个记忆目标摘要，含删除清理记录；无正文、来源、指纹、其他用户数据。轮询只读，不创建或消费意图。不是全部历史导出。
- POST `/api/personas/{p}/memories/{m}/sync/advance`：只接受空 JSON；先核对一个旧未决操作，必要时再派发一次当前目标。没有无限重试。已完成或已知失败的重复 advance 只读返回状态。
- POST 同路径 `retry`：仅已验证 OFFLINE/NOT_APPLIED 的最新 FAILED 且无未决旧项可创建新一代目标；新 UUID、新递增修订、retry_of 指向原操作。不会立即再次执行；UNKNOWN 不允许创建重试。

结构化回执绑定版本、模式、project/persona/user/memory、operation UUID、日志修订、RETAIN/DELETE、APPLIED/NOT_APPLIED 和有限安全代码。消费者先匹配所处理意图，再由日志服务重新验证，拒绝把另一条合法操作的回执误结算到当前操作。重复相同终结幂等，矛盾终结冲突；旧回执只能结算旧操作，不写回 SQL 记忆或改变最新目标。非法/空回执、异常和不确定结果保留 UNKNOWN，不拿错误消息、超时或未查询到记录当成功。

离线 target 与记忆修改持同一人物锁，再核当前权限、项目、确认来源及版本。模拟投影和不可变回执同事务：

1. 派发后、投影前崩溃：reconcile 在没有回执时写入持久 NOT_APPLIED/MOCK_FENCED 取消屏障。晚到 apply 必须遵守该屏障，不能重新投影。
2. 投影/回执已提交、日志未结算：重启只读已有回执结算，不再次 apply。

第一种是这个本地模拟器经同锁验证的取消契约；不是“远端 404/无记录所以可以重发”的供应商规则。真实 Hindsight 是否提供等价可验证终结/取消证据仍未验证。

用户权限由 Java 当前 actor/项目重查，负责人不能控制他人的私人意图；客户端不能传 bank、URL、Provider 或回执。状态变更后页内刷新，切人、离开、退出清空/丢弃晚响应；重复点击被限制。错误态清除过期摘要。旧 fixture ACKED 单独标为“旧测试结果，未证明同步”。
