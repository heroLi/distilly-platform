## 评测边界与冻结政策

新开发集 84 条，新独立保留集 80 条；两者由不同代理编写，只含合成资料。保留题面及答案不用于实现或调参。先在未修改的实际 API 上生成基线；实现者只看开发集诊断。候选算法在读取保留结果之前保存代码、规则及数据集哈希。读过保留结果后不据其题面修改规则；如以后使用它们调试，需标为已暴露诊断集并另建保留集。不能从验收问题、答案或特定实体生成查询→结果表。

每例独立空间及已发布人格，检索只可返回当前空间、人格已选中、当前 APPROVED 且未归档的工作资料。空间工作资料不是私人用户记忆；同空间 VIEWER 可读获准的工作资料，非成员拒绝。测试中故意插入不合法跨空间或未发布选择，检验最终 SQL 边界，而不是绕过产品配置作为正常流程。

正例包括原词、正字变体、有限词形、词面改写；中文同义及跨语言目标可如实未解决。否定记录可与问题相关，返回时必须保留原否定文本，不能转成肯定事实；严格实体/日期查找的异值、无关话题及无权限资料作为负例。资料记录卡检索不等于证明问题命题为真。

每个 split 分别报告文档级 TP/FP/FN、precision/recall、正例 hit@12、exact-set、空预期误返回、拒答/权限拒绝与可追溯性。访问泄漏、返回不在当前权限来源、原文/版本不符和读取写入业务状态必须失败。质量目标未达写失败分类，不删题，不把 JUnit 执行通过当所有语义目标通过。每例保留类别与预期/实际来源键，原文只用新公开合成 fixture。

## 拟议的最小规则（不接模型）

限定在工作知识召回，私人记忆和经历检索不改。候选使用 Unicode NFKC + Locale.ROOT 仅规范化匹配文本，返回仍是完整原文和当前来源版本；Latin/数字/下划线标识按整词匹配，避免单词子串。对纯 ASCII 单词做有界、通用的复数词形候选，不设问答或同义词对照表；英文功能词不作为主题锚点，英文内容词与显式数字保守匹配。汉字仍用 bigram 词面相关性，不能因此称为语义理解、翻译或事实推断。top12 / 16000 字符、权限筛选、发布与纠错栅栏不变。

这些规则可能改善正字、词形覆盖和子串误召回，仍可能误召回中文实体/日期问题或漏掉真正改写。不得用四个已知配对硬编码“语义通过”。不安装模型、不联网调用供应商、不改变真实文字费用门禁。

冻结集隔离审查发现：开发/保留正文完全重复 0；保留集 80 条中 7 个查询与开发集相同，9 条有具体词汇或改写家族复用。两集均保持原哈希，不为分数删题或重划。80 条仍是保留主分母，71 条未识别重叠的子集只可补充报告，不能称 80 条均完全未见或家族隔离。审查元数据只含案例 ID 与哈希，不含保留题面答案。

实际原实现基线已执行 164 条（两个 split），权限/来源/无写入安全断言通过。实现侧此时仅查看开发结果：68 个正例命中 37（54.41%），返回文档 precision 64.91%，TP 37 / FP 20 / FN 31；15 个空预期中误返回 5；非成员拒绝 1/1，越权和来源错误均 0。保留结果已保存原始 JSON，但在候选算法冻结前不查看其指标与逐例结果。语义目标未达不能称基线质量通过。

候选 V1 在开发集单次执行后、保留结果查看前冻结代码与语料哈希。开发集正例命中 56/68（82.35%），precision 94.92%，TP 56 / FP 3 / FN 12；空预期误返回 1/15，拒绝非成员 1/1，权限/来源/读取写入错误均 0。未为开发集或保留集加入问答、翻译、同义词映射。

明确局限：英文内容词全需匹配可能漏掉自然改写或额外解释词；功能词同形实体（如人名或月份）可能被忽略；ASCII 复数启发式有不规则词、歧义词干及其他词形盲点。日期只要求数字 token 存在，不验证完整日期顺序、范围或实体关系。中文仍只靠任一 bigram 相关性，不能验证中文实体或极性；query 的英文否定功能词不作为主题锚点，源文否定保留，但命中不能证明问题命题为真。私人记忆及经历检索未改、未据此验收。
