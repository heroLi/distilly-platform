## 当前可用

一个 UTF-8 TXT 合成导入可经 mock Worker 提取、负责人审核发布、人格选中后，通过独立记录卡首问查看当前资料。负责人修改已审核记录会发布新版本；再次核对读取新版本，取消选择或撤回资料后清除卡片。该路径不调用模型，不写私人聊天或记忆，不把工作资料说成人物亲历。原材料与历史证据不被手工修订覆盖；人工修订文字本身不等于经独立证实的事实。

虚拟经历台 → 工作空间设置新增只读合成账本。演示环境 OWNER 可看同一快照的额度、模拟已计费、占款、可用余额、未决笔数及分页条目。默认未决包含 RESERVED 和 UNCERTAIN；可查看四种状态及按序事件。金额同时显示整数分和元；SETTLED 只把实际模拟金额计入支出、返还预留差额；RELEASED 返还全部；UNCERTAIN 保留全部占款，不伪装成 0 元。刷新时先清旧快照，当前失权、切空间、退出及页面离开会清理金额与详情。没有创建、结算或真实模型调用按钮。

新增 `GET /api/projects/{project}/synthetic-costs/reservations?page=1&size=20&status=UNRESOLVED`。状态允许 UNRESOLVED / ALL / RESERVED / UNCERTAIN / SETTLED / RELEASED；size 1–50、page 1–1000000。列表、计数和摘要在同一空间锁事务中读取，稳定按 created_at DESC、id DESC 排序。接口保持 OWNER + demo 门槛及 `Cache-Control: no-store`。空状态参数遵循 Spring 默认未决。页面只发 GET，不改变账本。

## 安全的本机演示启动

先在 Java 17+ 与 Maven 可用的环境构建：

```sh
mvn -B -ntp -f server/pom.xml package
python3 scripts/run_synthetic_demo.py --port 18080
```

打开本机 `http://127.0.0.1:18080/knowledge.html#settings`，使用公开演示令牌 `demo-owner`。编辑者和阅读者为 `demo-editor` / `demo-viewer`，不能读取合成账本。新启动的演示库会显示空态；有合成账本记录的库可在设置页查看记录。

此启动器只继承工具链与区域设置白名单，不加载 `.env`，不继承供应商凭据、代理或真实数据库配置；固定使用 mock Worker、回环监听和独立的 `data/synthetic-demo/platform` 文件 H2，保留其中已有演示记录，不重置原库。停止时向下传递信号以清理 API/Worker。它不构建缺失的 JAR。此地址仅限本机；本轮没有公网部署或持续私有预览，也不承诺云工作区销毁后数据库仍存在。

自动化演示：`python3 tests/record_cards_e2e.py --browser` 验证 TXT→首问→真实纠错表单→再次问答；`python3 tests/synthetic_cost_page_e2e.py --output server/target/synthetic-cost-page-e2e` 打开原生 Chromium，创建四种合成状态、分页并验证页面清理。测试创建独立临时库，结束后清理进程，不保留对外服务。显式日期/精确编号的原生浏览器闭环为 `python3 tests/record_filters_e2e.py`，覆盖条件、纠错后旧条件无回退及同库重启。完整回归入口为 `python3 scripts/verify.py --e2e`。

首次创建到绑定后聊天的原生浏览器演示：`python3 tests/personality_journey_e2e.py`。手动从人物工作室创建合成人物，点“去人格库创建”，上传合成 TXT，显式沿用人物设定并确认材料授权，生成、审核发布、绑定、返回该人物开始交流。该入口不会复制材料授权勾选。

## 仍阻塞首版真实文字能力的功能缺口

1. **语义召回**：新建、单独标记的窄合成探针复现了 摄影→拍照、散心→漫步、coffee→咖啡、安静→宁静 四组在当前确定性记录卡路径均未命中；原词正对照均命中。探针报告为 `server/target/record-semantic-probe.json`，`historical_corpus_restored=false`。测试通过只说明探针执行和正对照成立，不表示四组语义目标通过；不等价于缺失的原独立样本、记忆路径或模型质量复验。后续已新增独立词法开发/保留评测及有限 Unicode/词形规范化，结果、9 个家族重叠和剩余漏召见 `NORMALIZED_LEXICAL_RETRIEVAL_2026-10-21.md`；四组探针仍 0/4。本轮又新增独立显式日期/编号筛选，契约、开发/保留结果及其变换类别重合见 `RECORD_LITERAL_FILTERS_2026-10-21.md`。这些改进不解决普遍语义、跨语言或人物回答质量，不能只为四个词硬编码“通过”。仍不下载或安装本地模型。
2. **真实调用与费用（用户已后置）**：已有合成全局执行预算、阶段/租约关联和未知占款保护，见 `TEXT_EXECUTION_BUDGET_2026-10-21.md`；合成账本、离线用量适配和估算都不是供应商真实账单。现有真实文字出口保持关闭，真实累计上限仍为已批准的 10 元，历史真实消费未知不能默认 0。本轮不等待账单样本、不新增计费实现或调用真实模型。
3. **真实回答质量**：mock/本机 HTTP fixture 和确定性记录卡证明流程与边界，不证明真实模型忠实度、人物一致性或多轮质量。真实接入还需要经授权的合成情境集、验真费用和输出评审。不能把旧文档中的历史“协议验证”当作本轮真实质量验收。

生产 PostgreSQL、身份系统、备份/存储生命周期和部署属于独立后续验收；当前不买资源、不部署。旧跨空间竞态部分浏览器历史边界与缺失 A 实现继续按未恢复/未复验记录，不能由本次账本页面测试冒领。
